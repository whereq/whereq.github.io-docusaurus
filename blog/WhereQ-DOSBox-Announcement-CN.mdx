## 角落里那台机器

我记得的，是风扇的声音。

不是游戏，不是跟软驱较劲的那几个晚上——是风扇。一台米色的主机蹲在父母客厅的角落，风扇转起来像是它正在想什么事情；旁边是一台带点偏绿、微微凸起的 CRT 显示器，那在当时，已经是一扇**窗**。

那台机器开着的时候，整个房间的温度都不一样。它是家里最吵的东西，而它属于我。

然后，是那个闪烁的光标。

```
C:\>
```

这个提示符像是一句邀请。它不自作解释，它只是**等**着。如果你愿意学它的语言——`cd`、`dir`、`copy`、`mkdir`——它就会老老实实照你说的做。那是我第一次觉得，电脑是一件**工具**，而不只是一个用来消费的家电。

## 游戏，以及游戏底下的软件

我玩过的那批游戏，现在说来都算经典了：**Wolfenstein 3D**，软盘被磁头刮花到根本读不出来，我用的是一张有划痕的；**Commander Keen**，一座明显是两个喝多了咖啡的人做的城市；凌晨两点跟朋友用拨号线路联机打 **Liero**；**Prince of Persia**，它教会我必须经常存档，因为我会死很多次；还有 **Duke Nukem** 和初代 **Doom**，以及 shareware 那种特定的魔力——这一集恰好断在你知道下一集会从哪里开始的地方。

但真正改变我人生的，其实不是这些游戏，而是游戏**周围**的软件——以及"它们不过就是磁盘上的文件"这件事。

我写了人生第一个 `.BAT` 文件。我敲了一条长到需要换行的命令，于是不得不去学"行连接符"。我用文本编辑器打开一个配置文件，改了一行，然后程序的行为就变了。我见过蓝屏，也因此明白：电脑是会坏的；坏是有原因的；我可以去找出那个原因。

然后——那个把我的人生彻底拐向另一个方向、也正是我整个职业生涯起点的瞬间——我意识到：**程序不是魔法，它就是文本。**

> **我可以打开它、读它、改它、弄坏它，然后重新把它拼回来。**

Turbo Pascal、BASIC、AUTOEXEC.BAT、CONFIG.SYS——它们看起来都是同一个东西换了不同的戏服。那都是某一个人坐下来写下的一串指令，而机器听命了。

这就是**启蒙**。软件从一个黑盒子，变成了一个**你伸得进手去**的东西。此后我做的一切——分布式系统、Kubernetes 集群、AI Agent、包括这个网站——都是从那个瞬间长出来的：**机器不是一个魔法盒子，它是一台你可以读懂的机器。**

## 然后，整个世界搬进了我们的口袋

然后，世界有了自己的屏幕。

看看手机变成了什么。它是相机，是钱包，是图书馆，是报纸，是游戏机，是地图，是电话，是银行，是医院，是教室。对今天绝大多数人来说，手机**就是**那台计算机。阅读、工作、游戏、学习、思考，全都发生在它上面。计算的重心，就这样悄无声息地挪了过来。

这也意味着一件有点可悲的事：那个"数以百万计的人通过命令提示符去**驾驭**一台机器"的时代，结束了。DOS 年代不只是"旧"——它更是一扇已经关上的门。那一代人第一次真正接触电脑，是从一个闪烁的光标开始的：它问你，你想做什么？而我们这一代，看到的是一堵墙的矩形，永远不必知道底下是什么。

我并不认为这一定更糟。我不是来说"手机不是一台好电脑"的。但我确实觉得，这让我们失去了一些东西。整整一代人对机器的**主人感**，来自于"你不得不"学会命令行。今天没有人再递给你一个光标了，你拿到的是一屏的应用图标，然后你永远不必知道它们下面是什么。

所以有个问题一直在我脑子里转，简单到有点不好意思问出口：

> **为什么不把 DOS 带到手机上去？**

不是为了做个博物馆展品，不是做一个在网页里跑 demo 的怀旧 App。而是做成一个**真的**东西——真家伙，在你自己口袋里那台真正的机器上跑，用你自己的 DOS 游戏和软件，就像当年本该有的样子。

这就是答案。今天，我把它开源了。

**WhereQ-DOSBox** 是 **DOSBox** 的原生 Android 移植版——模拟器核心以真正的原生库（`libdosbox.so`）的形式跑在 APK 里面。不是网页，不是 WebView，不是在 JavaScript 里再模拟一遍 x86。在你的手机上，以原生速度运行。

今天就能做到的事情：

- 在手机挂载的驱动器上运行你自己的 DOS 软件和游戏。
- 用屏幕键盘打字——按键直接进 DOSBox。
- 把触摸屏当成 DOS 鼠标来用。
- 全程离线，不需要账号，不需要浏览器，也没有任何追踪。

APK 大约 **5.3 MB**，支持 **arm64-v8a、armeabi-v7a 和 x86_64** 设备（Android 5.0 及以上）。

### 它是开源的 —— 请直接去看

这是一个 GPL-2.0 的项目。DOSBox 核心以 `AUTHORS`、`ChangeLog`、`COPYING` 和逐文件头部完整的形式嵌入进来，完全符合许可证的要求。整个移植只动了核心里的四个地方，都是很小的局部改动；其余全部是上游代码。

有一点我想说得很坦白：**这篇文章不是文档。** 文档就是仓库本身——构建指南、移植记录、性能测试报告，以及移植部分的每一行代码，全都在公开的地方。我宁愿你自己去读，而不是听我在这儿说。

👉 **[github.com/whereq/whereq-dosbox](https://github.com/whereq/whereq-dosbox)**

想自己编译一份：

```sh
git clone git@github.com:whereq/whereq-dosbox.git
cd whereq-dosbox
bin/build.sh all      # bootstrap + native + android + apk
```

跑完，`whereq-dosbox-debug.apk` 就在 `build/apk/` 里。完整指南——包括发布签名、Gradle 那一套、启动图标——都在 **[BUILDING.md](https://github.com/whereq/whereq-dosbox/blob/main/BUILDING.md)**。

### 我为什么要把它放出来

因为我一直在遇到这样的人：他们记得 DOS 那个年代，**想要**它回来——但已经悄悄地接受了"那是不可能的了"，把它跟米色主机、和 3.5 寸软盘一起归档了。

它没有消失。它只是在等一次移植。

如果这能让某个人重新找回一个晚上的一句 `C:\>`、一个下午的 Commander Keen，或者让一个从来没有过米色主机的小孩第一次体验到"哦——**原来是这样运作的**"，那这几个月的移植就值了。

如果你也想起了什么，也请一定告诉我。

## 谢谢，DOSBox

没有 DOSBox 项目，这一切都不可能。

**DOSBox** 是由 [DOSBox 团队](https://www.dosbox.com/crew.php) 写出来的——一群志愿者，把一个 1994 年的操作系统做到了世界上此后每一台机器上都能跑，包括那些当时还不存在的机器。他们让它兼容了大量 DOS 游戏，三十年里一直维护着它，而且这一切都是免费的、送给任何想要的人的。WhereQ-DOSBox 只是叠在他们工作之上的一层薄薄的壳。原创、手艺和慷慨，全部属于他们。

这个移植建立在 **[Em-DOSBox](https://github.com/dreamlayers/em-dosbox)** 之上——[Boris Gjenero](https://github.com/dreamlayers) 用 Emscripten 做的 DOSBox r4305 版本；而 Em-DOSBox 本身，起源于 [Ismail Khatib](https://github.com/CeRiAl) 第一次尝试用 Emscripten 编译 DOSBox，后来又搭上了 [Alon Zakai](https://github.com/kripken/) 在 Emscripten 上的工作。他们每一位，都把"DOS 跑在浏览器里"这件事往前推到了当时没人想得到的地方——而正是这个想法，让"DOS 跑在手机上"变得值得一试。

谢谢你们。全部的功劳都属于你们。**DOSBox 是 DOSBox 项目的商标**；本移植与 DOSBox 团队无隶属关系，也未获其背书。
