存档是这个模拟器存在的理由。它把整台机器冻住——CPU、DOS 内存、显存、打开的文件句柄、硬件定时器——让你能回到离开的那一刻。

在这一版之前，这台冻住的机器住在应用自己的私有目录里。而 Android 会在你卸载应用的那一刻，把那个目录一起删掉。

于是事情往往是这样发生的：手机存储满了，或者应用开始出怪问题，或者你只是想重装一遍。你重新装上 APK，游戏压缩包还在你选的那个文件夹里，你按下 **Play**——游戏却从第一关开始了。

十个小时的进度没了。不是因为游戏丢了，而是因为应用没了。

手机掉进河里，也是同一个道理：应用没了，存档跟着没了。

## 存档搬到应用外面了

修法并不复杂：存档不再待在 Android 可以随手删掉的地方。

在手机上选一个文件夹——**Config → Saves folder**，或者第一次存档之后弹出来的那句询问——之后每个档位都会镜像到那里，压成 gzip，就放在游戏旁边：

```
  应用                              你选的那个文件夹
  ──────                          ────────────────────
  存档   ── gzip ──▶                STARFALL/
                                    slot1.gz
                                    slot2.gz
                                    bundle.zip      (游戏本身)
```

于是游戏归你了，在你自己挑的文件夹里，它们的存档也已经躺在旁边。

而且这个文件夹并不是什么特殊的地方。它就是手机存储里一个普普通通的文件夹：可以复制、可以同步、可以搬家、可以丢进网盘，跟你对待任何一个装着文件的文件夹没有区别。选之前有一件事要知道：Android 不允许应用直接占用 **Download** 这个目录，那权限太宽了。挑别的就行——**Documents** 就很好。

有个细节值得知道，因为它是那种悄悄弄丢进度的东西：同名的两个压缩包会按名字区分——*game* 和 *game (2)*——所以它们的存档不会混到同一个地方去。

## 存档文件里该记什么

这一版的另一件事在存档文件内部，说的是鼠标。

DOS 程序不只是读鼠标，它还要配置鼠标：注册事件回调，规定光标能走到的范围，选一个光标形状和形状里的热点，再决定移动有多粗、有多敏感。这些都是游戏的属性，而游戏自己不会再发一遍。所以存档必须带着它们。

1.0.0.11 带得太多了。它把整个 INT 33h 驱动塞进了快照——事件队列、点击计数、中断重入标志全都在内。读回这样的快照，靠鼠标操作的游戏就卡死了：过期的队列和卡住的标志会把乱七八糟的东西塞进中断处理程序，塞进游戏自己的回调，读档时游戏可能直接挂住。机器回来了，鼠标却再也送不到游戏手里。

所以现在，快照只带着程序自己重建不出来的那部分配置，把运行时的状态留在外面：

| 存档里有的 | 存档里没有的 |
|---|---|
| 游戏注册的事件回调 | 排着队等处理的事件 |
| 光标的范围和当前位置 | 点击计数器 |
| 光标的形状和热点 | 中断重入标志 |
| 粒度和灵敏度 | 当时按着哪些键 |

光标的形状和别的同样重要。少了它，屏幕上那个光标会退回默认的方块，不再和真正的点击位置对齐，于是你的手指点在了目标旁边，而不是目标上。

读档不再带回来的，是存档那一刻的运行状态。那属于过去，不属于你要回来的这台机器。读档之后，游戏从鼠标松开的状态重新开始——如果你存档时正按着某个键，读完档要再按一次。

## 两件必须说清楚的事

### 旧存档读不出来了

**1.0.0.11 以及更早那几个 1.0.0.12 切出来的存档，这一版读不了。** 鼠标那一块改了之后，存档文件的版本也跟着长了一版，老存档会被拒绝，而不是被误读。这样做是诚实的——只读懂一半的存档，比读不出来的存档更糟——但这也意味着那些档位确实没了。

### 这一版重新打过

标签还是 `v1.0.0.12`，但下载链接后面那个文件，和最初用这个名字发布的那一个不是同一个构建，校验和自然也不一样。下面这个校验和是当前这个文件的。如果你在更早的时候下载过这一版，发现对不上，那是预期之中的。

```
sha256: 67577d59e078cd2953c24ea24753068aae2a01c2cf27a9788644787e999f2fd9
```

APK 本身在这里：[whereq-dosbox-1.0.0.12.apk](https://github.com/whereq/whereq-dosbox/releases/download/v1.0.0.12/whereq-dosbox-1.0.0.12.apk) —— 签名证书的 SHA-256 是 `b16b480d5a1ff6d35baff0b15fa3fc4b0ee815e500861fbff1b062c9bf7d3933`。

要装这一版的人注意一件事：这一版在手机上的名字是 **A-DOS**——Android 和 Apple 上的 DOS。包名还是 `com.whereq.dosbox`，签名密钥还是原来那一个，下载文件名和标签也仍然是项目自己的，所以它可以直接覆盖安装 1.0.0.11，不用先卸载，你的游戏和档位都原地不动。

它跑在 **arm64-v8a、armeabi-v7a 和 x86_64** 设备上，要求 Android 5.0 及以上，完全离线，不需要账号，也没有任何追踪。项目采用 GPL-2.0 许可，DOSBox 核心连同它的 `AUTHORS`、`ChangeLog`、`COPYING` 和逐文件的头注释一起嵌入。
