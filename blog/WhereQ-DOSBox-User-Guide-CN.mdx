## 一份我想要却找不到的指南

在自己的手机上试用这个应用时，我注意到一件事：我读过的每一份 DOSBox 指南，作者都默认你已经知道 `.zip` 包是什么。他们直接从有意思的部分讲起——声音芯片、存档格式、JIT——然后假定你从 1994 年起就一直在用 DOS。

对大多数拿着手机的人来说，这个假定是错的。把老游戏搬上现代手机，难的从来不是模拟器，而是最初那五分钟：怎么把游戏**弄进手机**，而且是应用能启动的形状。

所以我干脆写了一份我想要的那一份。七个步骤，每一步都配一张真机截图，不假设你见过命令行。

<!-- truncate -->

## 五分钟版本

1. 安装应用（APK 在[发布页](https://github.com/whereq/whereq-dosbox/releases)）。
2. 打开它，落到 **Files** 面板，里面是空的。
3. 按 **+ Install a bundle (.zip)**，选一个 `.zip` 游戏文件。
4. 按 **Play**，游戏就开始了。
5. 随时按左上角的 **File** 回到列表。

就这么多。下面全是这五步背后的细节——想弄明白在做什么就读，想直接玩就跳过。

## 开始之前

| | |
|---|---|
| 手机 | Android 5.0 及以上，手机平板都行 |
| 空间 | 应用大约 60 MB，再加上游戏本身的大小 |
| 网络 | 应用和游戏都在手机上之后，不需要网络 |
| 账号 | 不需要 |

你还需要**一个游戏**，单个 `.zip` 文件。这里说的「游戏」不是把你自己的文件打个 ZIP——往下看[游戏从哪来？](#游戏从哪来)。

应用不在源码仓库里。它由发布流水线构建，发布在[发布页](https://github.com/whereq/whereq-dosbox/releases)上，文件名是 `whereq-dosbox-<version>.apk`，旁边还有一个 `.sha256` 文件写着校验和。

### 游戏从哪来？

这里的游戏是一个形状固定的 `.zip`：

```
  the bundle
  ─────────
  PLAY.BAT          the entry point - the app runs this
  <the game files>  whatever the game needs
  __meta.json       the name the app shows in the list
```

就这些。仓库里附送了一个，你可以照着看形状、马上试起来：[`examples/game-bundle`](https://github.com/whereq/whereq-dosbox/tree/main/examples/game-bundle)——就是 **STARFALL** 演示版。把那个文件夹里的 `whereq-demo-bundle.zip` 拷到手机上装上就行。

至于真正的游戏：还在托管这些废弃 DOS 游戏的站点，一般都直接给 `.zip`。如果某个游戏的压缩包里只有游戏文件、没有 `PLAY.BAT`，应用是起不来的——自己写一个 `PLAY.BAT` 去运行游戏的可执行文件，再把文件夹压一次。

## 第 4 步 —— 键盘和鼠标

不用外接实体键盘，因为屏幕键盘**就是**键盘。横屏时画面两侧会出现两块键盘区，像掌机那样摆：左边是方向键组成的十字键加半边 QWERTY，右边是动作键（Alt、Ctrl、Shift、Space、Enter）和另外半边字母。

两个键可以切换键盘区显示的内容：

| 键 | 显示 |
|---|---|
| **#+=** | 标点层 |
| **Fn** | F1–F12、Ins/Del、Home/End、PgUp/PgDn、Caps、PrtSc、Pause |

切换之后，那个键会亮着。

**修饰键有两种用法。** *点一下* Ctrl、Alt 或 Shift，它会保持按下状态等你按下一个键——先 Ctrl 再 C。*按住*它，它的表现就和一个真正的键一样：手指按着多久它就保持多久，游戏里那些开火键、侧移键正是这么用的，另一只拇指同时操控方向。

**鼠标就是屏幕本身。** 你的手指就是鼠标：拖动是移动指针，点一下是点击，屏幕上的 **RMB** 键（左边那块，紧挨 **Tab**）是鼠标右键——在大多数 DOS 游戏里那代表*取消*或*返回*。在画面上**按住第二根手指**也是同一个意思，而且是在那根手指自己的位置上。

把手机转成竖屏，两块键盘区会折成底部的一条，适合画面高比宽大的游戏。

## Game Mode —— 一台掌机手柄

有些游戏要的是手柄，不是打字机。**Game Mode** 把两块键盘区换成一台游戏台式的手柄：八向方向键、一颗轨迹球，外加 DOS 游戏真正用来开火、跳跃和横移的那几个键。

<p align="center">
  <img
    src="https://raw.githubusercontent.com/whereq/whereq-dosbox/main/docs/screenshots/android-n8-24-game-mode-hybrid.png"
    alt="Hybrid 档案下的 Game Mode：左边是 L-CLICK、R-CLICK 两个鼠标键，下面是八向 D-pad 和 ARROWS 按钮；右边是 Y、X、CTRL、ALT、轨迹球、SPACE 和 ENT。"
    width="900"
  />
</p>

<p align="center">
  <sub>Game Mode。字母键盘没了，换成 D-pad 和轨迹球，还是占着原来那两条黑边。</sub>
</p>

**进出都要一点老派仪式感。** 键盘显示着的时候，先打开 **Caps Lock**——双击 **Shift**，那个键会亮成蓝色并写着 *CAPS*——然后在键盘上敲那段 **Konami 暗号**：**↑ ↑ ↓ ↓ ← → ← → B A**，两块键盘区就翻成了 Game Mode。那个 **B** 和 **A** 必须是*大写*：暗号按字母实际打出来的大小写来匹配，小写的 "ba" 只会老老实实地把 "ba" 打进 DOS 提示符。要退出来，就在手柄上再敲一遍同一段暗号：方向键上的 **↑ ↑ ↓ ↓ ← → ← →**，然后按 **X**、**Y**（这两个面部键替 B 和 A 上场）。手机的**返回键**同样能把你带回键盘。

左上角那个金色按钮写着当前的**档案**；点一下轮换，长按打开选择器。每个游戏都记住你上次和它一起用的那一个档案，以及方向键的输出模式。

**轨迹球**移动指针的方式像笔记本触控板——划一下动一点，**轻点就是点击**——而不是一下子跳到你按下去的地方。在 Hybrid 里，按住 **L-CLICK**（左肩键）同时滚轨迹球，就是框选。

### 方向键有三种方言

DOS 游戏对「上」这个方向各说各话。D-pad 下面的 **ARROWS** 按钮轮换手柄到底发什么，应用会按游戏记住你选的那一种：

| 模式 | 上 / 下 / 左 / 右 | 斜向（比如上右） | 适合 |
|---|---|---|---|
| **ARROWS** | 方向键 ↑ ↓ ← → | **同时按两个键**（↑ + →） | 大多数游戏——凡是读方向键的 |
| **NUMPAD** | 数字小键盘 8 / 2 / 4 / 6 | **单个键**——7 / 9 / 1 / 3 | 按小键盘做的游戏，斜向自成一个键（很多 roguelike 和小键盘映射的游戏） |
| **WASD** | 字母 W / A / S / D | **同时按两个键**（W + D） | 后来的射击游戏，以及一切绑定了 WASD 的游戏 |

所以差别有两层：*按哪些键*，以及*斜向怎么发*——ARROWS 和 WASD 是把相邻的两个键一起按下去，NUMPAD 则八个方向各有各的键。游戏完全不理方向键的话，八成是模式不对：用 ARROWS 按钮一路换到它有反应为止。

### 重新映射一个按键

有时候游戏要的键手柄上没有——用 **F** 开火、用 **SPACE** 跳跃、拿**数字小键盘**射击。任何 Game Mode 按键都能改教它发别的键，而且应用会按游戏记住。

**长按那个金色的档案按钮**（左上角，写着档案名字的那个），选 **Remap buttons…**。屏幕进入*映射模式*：顶部一条横幅写着 *"Tap a button to remap"*，可以改的按键镀着金色描边。**点其中一个**，会弹出一串按键，挑你想要的。**DONE**（或者那条横幅）就退出映射模式。

  <img
    src="https://raw.githubusercontent.com/whereq/whereq-dosbox/main/docs/screenshots/android-n8-28-game-mode-remap.png"
    alt="Action 档案下的映射模式：顶部横幅写着 Tap a button to remap，旁边是 DONE 按钮；可以重新映射的 SHIFT、TAB、STR、ENT、USE 和 JUMP 带着金色描边，金色的 FIRE 按钮带着深褐色描边，Y 和 X 没有描边。"
    width="900"
  />
</p>

<p align="center">
  <sub>映射模式：金色描边标出了可以改的按键；金色的 FIRE 按钮上得用深褐色描边，否则就看不见了。</sub>
</p>

| 可以改 | 不能改 |
|---|---|
| **CTRL、ALT、SHIFT、TAB、STR ◂、STR ▸、SPACE、ENT、USE、JUMP** 和 **FIRE** | **X** 和 **Y** 两个按钮（它们要回答游戏的 *Quit? (Y/N)* 提问，也要响应 Konami 暗号）、**ESC**、D-pad、轨迹球、鼠标键，以及功能键（**ARROWS**、**Fn**、**1–9**、**TURBO**、**SPEED**、**DRAG**、**DBL**） |

改过的按键会显示新键名，而不是原来的名字——**FIRE** 保留自己的名字，新键显示在它下面。列表里的第一项 **Reset to default** 可以还原。

重新映射按游戏保存，而且覆盖所有档案：不管你用哪个档案玩，这个游戏都记得每个键该发什么。

## 第 5 步 —— 存档

```
  inside the app                    the folder you picked
  ────────────                      ───────────────────
  the games                         <your folder>/
  the save-state slots                <game name>/
                                       slot1.gz
                                       slot2.gz
                                       bundle.zip

  gone when the app is removed     stays until you delete it
```

## 出问题了怎么办

| 你看到的 | 意味着 | 怎么办 |
|---|---|---|
| *「That save file is damaged」* | 这个档位是旧版本写的 | 存档格式升过版本号，太旧的档位会被拒绝而不是读错。重新存一个新档位。 |
| 游戏起不来 | 包里没有 `PLAY.BAT`，或者入口指错了 | 打开那个 `.zip`，确认 `PLAY.BAT` 能运行游戏的可执行文件 |
| 按 **Play** 没动静 | 模拟器正在重启来引导游戏 | 等几秒——进程是故意重启的，游戏会在新进程里起来 |
| 键盘挡住了画面 | 两块键盘区占了画面两侧 | 把手机转成竖屏，键盘会折成底部一条 |
| 鼠标点不动 | 游戏要的是「按住」状态 | 拖动用来移动；右键用屏幕上的 **RMB** 键，或者在画面上按住第二根手指 |
| **Download** 文件夹选不了 | Android 不允许应用占用整个 Download | 换一个文件夹，比如 **Documents** |
| 弹出通知授权 | 应用想发「回到游戏」的通知 | 允许或拒绝都行——拒绝只是少这条通知 |
| 游戏很卡 | 模拟器跑的是当年的硬件，不是快机器 | 这是 1994 年那台机器本来的速度，不是手机慢 |
