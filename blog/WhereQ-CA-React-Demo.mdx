## A library you cannot trust from a README

A component library is easy to publish and easy to ignore.

The README shows a picture of a button. The demo page shows a page somebody built *to look like* the library, with the real component never loaded. The actual code sits in somebody's app, behind a build step, where you cannot see it — so the one thing you want to check, *does this thing work when it is really installed?*, is the one thing nobody checks.

That is the gap this page closes.

**whereq.ca now has a live demo of @whereq/react — and a playground to try it in.**

The WhereQ Lab is built from one shared React component library. It lives on npm as `@whereq/react`, and the Lab now runs it in full: open `/react` and the real components from the published package render in front of you — not a screenshot of one, and not a story about one.

<!-- truncate -->

If the demo breaks, the package is broken. That is the whole point of it.

## 🧭 A page with a rail, a stage and a manual

Six primitives sit in the rail on the left: SearchBox, Tag, Toast, Avatar, Scrollbar and CountryFlag. Click one and the middle of the page becomes the live demo of that component, with the example code right underneath it. The column on the right documents the package, the install line, and what the component you just opened actually does.

## 📦 Open source, on npm and on GitHub

`yarn add @whereq/react` — six primitives, no runtime dependencies of their own (React is a peer), and the same package the Lab's own search box and tag chips are built from.

The repository is **[github.com/whereq/whereq-react](https://github.com/whereq/whereq-react)**, MIT-licensed, and the package is on **[npm](https://www.npmjs.com/package/@whereq/react)**. It has its own docs site, its own Storybook, and a zero-build demo you can open as a single HTML file.

## 🔧 And the United Kingdom flag renders again

The registry keyed it under `"uk"` while the demo asked for `"gb"`, so the chip came back empty. `"gb"` is the key now, `"uk"` stays as an alias, and an unknown country draws a neutral emblem instead of an empty box.

That one is worth writing down, because it is the kind of defect this page exists to catch: the flag was not broken in the demo, it was broken *in the package*, and it had been broken in the package the whole time. Nothing about a screenshot would ever have shown it.

**[@whereq/react](https://github.com/whereq/whereq-react)** is MIT-licensed and © WhereQ. **The Lab** — the map, the maths bench, the physics lab, the chemistry bench, the API explorer — is where all of this gets used first, which is why the playground and the library ship together.
