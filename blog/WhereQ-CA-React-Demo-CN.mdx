## 一份 README 说服不了谁

组件库这东西，发出去很容易，被真正用起来却很难。

README 里放一张按钮的截图。demo 页面往往是为了**看起来像**这个库而专门做的一页，真正的组件根本没被加载过。真正的代码躺在某个应用的构建步骤后面，你看不见 —— 于是最该回答的那个问题，*这东西真装上去以后到底能不能用？*，反而从来没人回答。

这一页要补的就是这个缺口。

**whereq.ca 现在有了 @whereq/react 的实时演示 —— 也多了一个可以上手试的游乐场。**

WhereQ 实验室就建在这套共享的 React 组件库之上。它在 npm 上的名字是 `@whereq/react`，而现在实验室把它整个跑了起来：打开 `/react`，已发布包里的真实组件就渲染在你面前 —— 不是截图，也不是关于它的介绍。

<!-- truncate -->

演示要是坏了，就是包坏了。这正是这一页存在的意义。

## 📦 开源，在 npm 上，也在 GitHub 上

`yarn add @whereq/react` —— 六个基础组件，自己不带任何运行时依赖（React 是 peer），实验室自己的搜索框和标签芯片用的就是这个包。

仓库在 **[github.com/whereq/whereq-react](https://github.com/whereq/whereq-react)**，MIT 许可；包发在 **[npm](https://www.npmjs.com/package/@whereq/react)** 上。它有自己的文档站、自己的 Storybook，还有一个零构建的单文件 demo，下载下来直接用浏览器打开就行。

## 🔧 而且英国国旗又回来了

注册表把英国登记在 `"uk"` 名下，而演示请求的是 `"gb"`，所以那个小格子一直是空的。现在 `"gb"` 才是注册表的键，`"uk"` 保留为别名；查不到的国家也会画一个中性的徽记，而不是一个空盒子。

这一条值得单独写下来，因为它是这一页存在的意义所对应的缺陷类型：出问题的不是演示，是**包** —— 而且这个毛病在包里一直都在。截图永远不可能让你看出这一点。

## 致谢

这东西站在别人的劳动成果上，得说清楚。

**[@whereq/react](https://github.com/whereq/whereq-react)** 是 MIT 许可，© WhereQ。它的 `Scrollbar` 最初是从 [whereq.cc](https://whereq.cc)（那个注重隐私的照片橱窗）里抽出来的 —— 当初写它，是为了让浏览器原生的滚动条变得好看，而不是把滚动条换掉。`Toast`、`Tag`、`Avatar`、`SearchBox` 和 `CountryFlag` 都是先为 WhereQ 自己的应用写的，后来才交了出来。

**[React](https://react.dev)** 是一个 peer 依赖，仅此而已 —— 这个库自己不附带任何运行时依赖。

**实验室** —— 地图、数学工作台、物理实验室、化学工作台、API 浏览器 —— 是这一切最先被用起来的地方，所以游乐场和组件库是一起发布的。
